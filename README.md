#  Personal Finance Tracker

Aplikasi web sederhana untuk mencatat dan mengelola keuangan pribadi. Dibangun menggunakan PHP Native (Vanilla) dan MySQL dengan arsitektur MVC.

## 🚀 Teknologi yang Digunakan
- **Backend:** PHP 8.3 (Native / Vanilla)
- **Database:** MySQL (via PDO)
- **Frontend:** HTML5, Bootstrap 5, Vanilla JavaScript
- **Server:** Laragon / Apache

## 📂 Struktur Proyek
Proyek ini menggunakan pola arsitektur **MVC (Model-View-Controller)**:
- `config/`: Konfigurasi database dan aplikasi.
- `controllers/`: Logika bisnis (Business Logic).
- `models/`: Interaksi dengan database.
- `views/`: Tampilan antarmuka (UI).
- `public/`: Entry point aplikasi dan aset publik (CSS, JS, Images).

## ️ Cara Menjalankan Proyek (Local Development)
1. Clone repository ini.
2. Pastikan Anda menggunakan local server seperti **Laragon** atau **XAMPP**.
3. Import file `database.sql` (akan dibuat di fase berikutnya) ke phpMyAdmin.
4. Konfigurasi koneksi database di `config/database.php`.
5. Akses aplikasi melalui browser.
